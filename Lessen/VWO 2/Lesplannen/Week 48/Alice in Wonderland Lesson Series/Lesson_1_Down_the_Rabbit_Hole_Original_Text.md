# Lesson 1: Down the Rabbit-Hole | Original Carroll text

**Subject:** English  |  **Class:** 2 VWO  |  **Duration:** 30 minutes  
**Text policy:** Use only the original Lewis Carroll extract printed in the student reader. Context notes, glossary, examples and questions are teacher-written, clearly separated from Carroll's words. Do not substitute the former adapted text.

**Chapter:** I, selected original scene with the bottle labelled DRINK ME.  
**Text length:** 175 words.  
**Stepping Stones connections:** Health vocabulary, safe choices, Stones 4 and 6, Grammar 3 and 4, reading strategies and false friends.

## Learning objective and success criteria

**Objective:** Students skim an authentic literary extract, scan for proof, infer meaning from context, identify a false friend in a separately written example, and apply present perfect and modals to the situation.

I can identify the main idea, copy exactly two dangers, explain why Alice checks the bottle, complete one present perfect sentence and give advice with *should* and *could*.

## Materials and preparation

Student Reader Lesson 1, screen/timer, highlighters, board. Display: **"You find a bottle labelled DRINK ME. What should you do?"** Set assigned pairs and voice levels 0/1. Pre-teach only *poison* = gif and *ventured* = durfde; keep the rest for context-guessing.

## 30-minute EDI sequence

| Time  | Phase                         | Teacher actions                                                                                                              | Student actions                                                 |     |     |
| ----- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | --- | --- |
| 0–3   | Starter and objective         | Display dilemma; collect two suggestions without debating the fictional outcome.                                             | Write one piece of advice individually.                         |     |     |
| 3–6   | Prior knowledge / exploration | Briefly contextualise chapter. Model **exploring** title/genre and preview unknown vocabulary.                               | Read context note, predict (Q1).                                |     |     |
| 6–11  | I do: skimming                | Read the original first paragraph aloud with pupils following. Model selecting the main idea without translating every word. | Read full excerpt once; answer Q2.                              |     |     |
| 11–17 | We do: scanning and TASK      | Decode Q3: **copy exactly TWO**; find the first danger. Ask for a second and where it appears.                               | In assigned pairs complete Q3–Q4; show evidence, voice level 1. |     |     |
| 17–21 | Meaning in context            | Teach *ventured* by its surroundings; distinguish author text from example sentences.                                        | Complete Q5–Q6.                                                 |     |     |
| 21–27 | You do: grammar and advice    | Brief reminder: **has + past participle**, **should/could + base verb**. Clarify original *had read* is NOT present perfect. | Individually complete Q7–Q8 and compare answers.                |     |     |
| 27–30 | Check and exit                | Use Q9 to demand textual evidence. Record instruction vs comprehension vs grammar errors.                                    | Q9 and share one safe alternative.                              |     |     |

**Homework:** Review unfamiliar original vocabulary; optionally write a 45-word note advising Alice.  
**Differentiation:** Support with a glossary of *poison, knife, wise, tasted* outside text. Stretch: explain why her decision is questionable despite checking the label.  
**Safety note:** This is fantasy. Do not frame tasting unknown substances as safe.
